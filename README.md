# おみくじアプリ（GUI 版ベース）

研修の最終成果物のためのベース（土台）です。
土台の骨組みに加えて、おみくじを引くロジック（データ層）と、ボタン操作を受け取って動かす部分（イベント層）はすでに完成して動いています。
残っているのは、引いた結果を画面に表示する部分だけです。
まずはステップ1でそこを完成させ、そのあと個人・チームで自由に拡張してください。

---

## 初回セットアップ

```bash
npm install
```

## 起動方法

```bash
npm run dev
```

表示された `http://localhost:5173/` のような URL をブラウザで開いてください。
（リポジトリの取得手順は別の資料にまとめてあります。）

---

## まず触ってみよう（ステップ0：配布状態）

1. ブラウザで開いて「おみくじを引く」を押す。
2. 画面の文字は「ここに結果が出ます」のまま変わらない。
3. しかし開発者ツール（`F12` →「Console」タブ）を見ると、`引いた結果: 大吉` のように結果が出ている。

おみくじを引くロジックは完成して動いています。
足りないのは、結果を画面に表示する部分だけです。これが最初の課題です。

---

## 全体の構成（3層に分かれています）

画面は `index.html` の1枚。プログラムは役割ごとに3つのファイルに分けています。

| ファイル         | 層         | 役割                               | 状態                  |
| ---------------- | ---------- | ---------------------------------- | --------------------- |
| `src/omikuji.ts` | データ層   | おみくじの型・比率・くじを引く関数 | 完成済み              |
| `src/render.ts`  | 描画層     | 状態を画面(DOM)に表示する          | 空（ステップ1で実装） |
| `src/main.ts`    | イベント層 | ボタンと処理を結びつける           | 完成済み              |

CLI 版（小まとめ）との対応:

- キーボード入力待ちの `while` + `readline` → ボタン + `addEventListener`（`main.ts`）
- `console.log` での結果表示 → `textContent` で画面に表示（`render.ts`）

## ステップ1（必修）：結果を画面に表示しよう

`src/render.ts` の `renderResult` が空なので画面が変わりません。ここを実装します。

やること:

1. 結果を表示するためのHTML要素を取得する。
2. その要素に、引いた結果を表示する。
3. `result` が `null` のとき（リセット直後など）は初期メッセージを表示する。

うまくいけば、「おみくじを引く」を押すたびに画面の文字が切り替わります。
ヒントは `src/render.ts` のコメントにあります。

## ステップ2以降：自由に拡張しよう（難易度別の例）

ここからは自由です。下は例なので、別のアイデアでも構いません。

### 易（HTML / CSS 中心）

- 結果やボタンの文言・色を変える（`index.html` の `<style>`）。

### 中（型・設計）

- 残りくじ枚数を表示する。`omikuji.ts` に残り枚数を返す関数を足してから `render.ts` で表示する（`tickets` は `export` していないので、外から数えるのではなく `omikuji.ts` の中に関数を足すのがポイント）。

### 難（複雑なDOM操作）

- 引いた履歴をリスト表示する。`render.ts` に履歴用の関数を足し、`createElement("li")` で項目を作って `<ul id="history">` に `appendChild` していく。`main.ts` で結果を配列に `push` して渡す。

各ファイルには「拡張ポイント」というコメントがあります。そこを手がかりに進めてください。

チームで開発するなら、「履歴担当」「残りくじ枚数担当」のように機能ごとに分担することもできます（任意）。

## 使ってよい技術・避ける技術

研修で学んだ範囲だけで作れるようにしています。

- 使うもの: TypeScript（型・関数・ファイル分割）、基本の HTML タグ、DOM 操作（`getElementById` / `textContent` / `createElement` / `appendChild` など）、`addEventListener`。
- 避けるもの: React/Vue などのフレームワーク。
